| 資源 | 改動 | 保留 | 原有繁中目標 | 單邊英文建議 |

| 介面 | 3,209 | 8,687 | 11,896 | 27 |
| 對白 | 8,591 | 293 | 8,884 | 66 |
| 合計 | 11,800 | 8,980 | 20,780 | 93 |

改動比例為 11,800 ÷ 20,780 = **56.8%**；保留比例為 8,980 ÷ 20,780 = **43.2%**。93 條單邊英文建議另列。

## 重繪圖表

安裝 Python 及 matplotlib，並指定支援繁體中文的字體檔：

```sh
python tools/readme_statistics.py --font /path/to/cjk-font.ttf
```

以凍結來源重新計算時，另加 `--ledger /path/to/review-ledger.json`。程序會先核對來源 SHA-256、資源鍵唯一性、原譯與回寫字串差異，以及逐項例子的修訂狀態。
